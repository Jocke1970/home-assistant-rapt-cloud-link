## Change

Adds dedicated freshness entities for diagnosing stale BrewZilla/RAPT Cloud
telemetry:

- `BrewZilla Telemetry Age` — seconds since latest telemetry `createdOn`;
- `RAPT BLE Thermometer BLE Data Age` — seconds since the latest telemetry
  carrying a valid `controlDeviceTemperature`.

These sensors are intended for Home Assistant Recorder/history so upstream
cloud upload cadence can be measured directly over time.

No BrewAssistant control behavior, source arbitration, or entity IDs of
existing sensors change.
