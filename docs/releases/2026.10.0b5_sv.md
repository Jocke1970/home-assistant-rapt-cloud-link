# RAPT Cloud Link 2026.10.0b5 – passiv tidsinformation och profilaviseringar

**Kanal:** HACS beta / GitHub Pre-release  
**Tagg:** `v2026.10.0b5` på validerad beta-merge-SHA efter separat `dev → beta`.
`main` ändras inte.

## Nyheter från 2026.10.0b4
- Den aktiva BrewZilla/RAPT-profilsensorn exponerar RAPT:s separata,
  **råa** sessionstid och återstående profiltid:
  `profile_current_time_raw`, `profile_remaining_time_raw`.
- `profile_step_progress_raw` innehåller oförändrad rå telemetri;
  ingen ogrundad sekund-/procentomvandling utförs.
- `step_alerts` innehåller en begränsad lista över RAPT:s aviseringar
  för **aktuellt steg** (upp till 16), med text, trigger och rå
  `length_raw` som inte kan tolkas som en verifierad nedräkning ännu.
  Råa tillsatsvärden får inte skapa ett automatiskt humlelarm.
- `profile_step_transition_observed_at` är en **ungefärlig**
  observationstid för ett riktigt steg-ID-byte som RCL sett över två
  följande framgångsrika API-polls i samma aktiva session.
  Vid HA-omstart, RCL-bortfall, ändrad session eller misslyckad poll finns
  ingen ny verifierad timerstart. Ett stillastående steg är normalt.
- Befintliga `profile_observed_at`, RAPT-profilens ägarskap,
  beviskrav för STOP och säker förbindelseförlust är oförändrade.

## Beroenden och avgränsning
Uppdatera **RCL b5 före BrewAssistant b10**.
BA kan efter det visa planerad steglängd och begränsat uppskattad återstående
tid för specifika tidsstyrda steg samt tillgängliga aktuella aviseringar.
Tillsatsernas tidsutlösare och RAPT:s faktiska timer måste verifieras vid ett
övervakat vattenprov innan exakta nedräkningar till humlegivor släpps.

Ingen ny START/STOP, värme, pump, target, automatisk step-advance eller
övertagning av RAPT:s session. Fysisk Mash In-pumpdiagnos ligger separat.

## Installation/test
1. Släpp b5 på `beta` efter 3/3 gröna valideringar och ny GitHub Pre-release.
2. Installera genom HACS med beta/pre-release aktiverad och starta om HA.
3. Bekräfta nya råfält under en aktiv RAPT-profil; inga falska
   stegklockor efter återanslutning.
4. Uppdatera därefter BA b10 och ersätt RAPT-profiltimerkortet i Lovelace.
5. Exakta tillsatsnedräkningar är inte aktiverade i denna release.
