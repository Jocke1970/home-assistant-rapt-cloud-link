# RAPT Cloud Link 2026-10-03 — beta candidate

**Repository:** `Jocke1970/home-assistant-rapt-cloud-link`  
**Base:** `brewassistant-raptcloudlink`  
**Candidate branch:** `fix/brewzilla-30s-polling`

## Change

The BrewZilla coordinator now uses a maximum idle polling interval of
30 seconds so BrewZilla-backed BLE/control-device temperature is observed
more frequently in Home Assistant.

- default 3-minute integration setting -> BrewZilla polls every 30 seconds;
- operator settings faster than 30 seconds are preserved;
- Pill and other RAPT coordinators are unchanged;
- profile/session STOP-attestation semantics are unchanged.

This does not guarantee fresh RAPT Cloud BLE telemetry every 30 seconds.
If repeated polls return the same `controlDeviceTemperature`, the remaining
freshness limit is upstream of RAPT Cloud Link.

No Home Assistant entity IDs or BrewAssistant discovery contracts change.
BrewAssistant itself does not require a code update solely for this polling
change.
